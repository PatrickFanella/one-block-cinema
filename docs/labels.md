# Labels

Suggested labels for Gitea/Open Pilot workflow:

- `ready-for-agent` — issue is structured enough for agent work.
- `agent:queued` — human approved automation pickup.
- `type:feature` — new capability.
- `type:bug` — defect fix.
- `type:docs` — documentation only.
- `type:chore` — repo/process/tooling.
- `area:ios` — Swift/iOS app.
- `area:backend` — future API/sync/community backend.
- `area:community` — challenges/comments/moderation.
- `area:product` — PRD/scope/roadmap.
- `priority:p0` — blocks useful development or launch readiness.
- `priority:p1` — important near-term work.
- `priority:p2` — nice-to-have or later.
